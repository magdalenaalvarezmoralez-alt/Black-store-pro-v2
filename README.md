# BLACK STORE PRO — versión 2.0

Tienda web de Black Store Colombia, enfocada en belleza, cabello afro, moda y accesorios con identidad.

## Mejoras incluidas
- Catálogo ampliado a 12 productos con imágenes individuales.
- Categorías de Cabello, Belleza, Moda Afro y Accesorios.
- Filtros por categoría.
- Buscador de productos.
- Favoritos visuales.
- Carrito lateral con cantidades y eliminación de productos.
- Carrito guardado en el navegador con localStorage.
- Pedido completo por WhatsApp desde el carrito.
- Diseño responsive para celular, tablet y computador.
- Hero renovado con imágenes individuales.
- Animaciones de entrada y microinteracciones.
- Se conserva el estilo negro/dorado y el logo original.

## Archivos
- `index.html` — estructura, catálogo y carrito.
- `style.css` — diseño responsive.
- `script.js` — filtros, búsqueda, favoritos, carrito y WhatsApp.
- `images/` — fotografías originales del proyecto + 12 artes de producto en SVG.
- `logo-black-store.png` — logo.

## Publicar en GitHub Pages
1. Sube/reemplaza los archivos del repositorio con este proyecto.
2. En GitHub entra a Settings → Pages.
3. Selecciona la rama principal y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique el sitio.
