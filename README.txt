BLACK STORE PRO v2 — LISTO PARA GITHUB

Este paquete ya tiene corregidas las rutas de las imágenes.
Las imágenes usan la extensión .jpeg exactamente como están guardadas
en la carpeta images/.

PARA PUBLICAR:
1. Descomprime este ZIP.
2. Entra a la carpeta que contiene index.html.
3. Sube index.html, style.css, script.js, logo-black-store.png y la carpeta images
   a la raíz de tu repositorio de GitHub.
4. Si GitHub pregunta si quieres reemplazar archivos, acepta.
5. En Settings > Pages, publica desde la rama main y la carpeta / (root).

IMPORTANTE:
No cambies los nombres de las imágenes ni .jpeg por .svg.
